# DevOps Lab 3: Docker Containerization

Лабораторная работа по контейнеризации приложения с использованием Docker и интеграции в CI/CD пайплайны

## Цель работы

Научиться упаковывать приложение в Docker контейнеры и интегрировать их сборку и развертывание в процесс CI/CD

## 📋 Обзор решения

### Docker образ приложения
- **Базовый образ:** Python 3.12.8
- **Порт:** 8181
- **Регистр:** GitHub Container Registry (GHCR)
- **Тегирование:** автоматическое по branch, PR и commit hash

### Обновленные CI/CD пайплайны
- **CI:** Добавлена сборка Docker образа после успешного тестирования
- **CD:** Развертывание через Docker контейнер вместо прямого запуска кода
