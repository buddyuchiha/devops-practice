# DevOps Lab 1: GitHub Webhooks Automation

Лабораторная работа по настройке автоматического развертывания Python приложения с использованием GitHub Webhooks

## Цель работы

Настроить автоматическую сборку и развертывание Python приложения при событиях в GitHub репозитории с использованием webhooks

## 📋 Описание проекта

**Приложение:** Catty - веб-приложение для управления напоминаниями  
**Стек технологий:** Python, FastAPI, HTMX, Jinja2, TinyDB
