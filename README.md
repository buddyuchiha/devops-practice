# DevOps Lab 4: Docker Compose

Лабораторная работа по управлению мультиконтейнерными приложениями с использованием Docker Compose и интеграции в CI/CD пайплайны

## Цель работы

Получить базовые навыки работы с Docker Compose, научиться управлять мультиконтейнерными приложениями и организовывать их развертывание через композ-стек.

## Обзор решения

### Мультиконтейнерное приложение
- **Веб-сервис:** Python FastAPI приложение (порт 8181)
- **База данных:** MariaDB 10.11
- **Сеть:** Изолированная bridge-сеть для межсервисного взаимодействия
- **Персистентность:** Docker volumes для хранения данных БД

### Обновленные CI/CD пайплайны
- **CI:** Сборка и тестирование приложения с последующей публикацией образа в GHCR
- **CD:** Развертывание через Docker Compose стек с автоматическим обновлением контейнеров
